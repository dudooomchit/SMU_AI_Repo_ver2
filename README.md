2일차 팀프로젝트: 문서 기반 RAG 시스템 구축
주제: Retrieval or scroll 방식 이용하여 신입생들의 원활한 학교생활을 위하여 신입생 설명회 PDF 를 기반으로 하여 답변을 하는 챗봇 제작.

3일차 팀프로젝트: 테이블 데이터 조회 시스템 구축
주제: 충청남도 천안시 착한가격업소 데이터를 활용하여 업소명, 업종, 대표자, 읍면동, 행정동, 소재지 등의 정보를 조회 후, 업종별 및 지역별 착한가격업소 현황과 분포를 분석할 수 있는 데이터 조회 시스템구축
사용한 데이터:충청남도 천안시_착한가격업소_20260326.csv
#1일차

## 1. 문제 정의
   대학 생활 정보와 공공데이터 모두 공개되어 있지만, 사용자가 원하는 정보를 정확히 추출해내기 어렵습니다.[2일차 RAG] 신입생 설명회 정보 안내문제점: 수십~수백 쪽 분량의 신입생 가이드/설명회 PDF 내에서 학사 일정, 수강신청, 장학금, 편의시설 정보 위치를 빠르게 찾기 어려움.해결책: 의미 기반 검색(RAG)을 활용하여 사용자의 질문과 가장 연관성이 높은 페이지를 자동 검색 후, LLM이 이해하기 쉬운 가이드라인 형태로 변환하여 제공.[3일차 Text2SQL] 착한가격업소 현황 및 분포 분석문제점: 텍스트 문서 검색 방식으로는 "OO동 한식 업소 총 몇 개?" 또는 "지역별 업종 분포 비율"과 같은 집계·분석성 질의 처리가 비효율적임.해결책: CSV 파일의 구조화된 테이블 데이터를 PostgreSQL(Supabase) DB로 정규화 구축하고, 자연어를 SQL문으로 변환(Text2SQL)하여 정확한 데이터 수치 추출 및 정형화된 통계 분석 제공.2. 사용 데이터2-1. 문서 데이터 — 2일차 RAG신입생 학사 및 대학 생활 가이드를 담은 공식 설명회 자료를 활용합니다.항목상세 내용사용 데이터2026_freshman_c.pdf (2026학년도 신입생 설명회 가이드)발행 기관상명대학교 (2026)처리 방식PyPDFLoader / UnstructuredPDFLoader 기반 텍스트 추출청크 분할Parent-Child Chunking 구조 (Parent: Page 단위 / Child: 400자, Overlap 50)선정 이유수강신청, 졸업요건, 학사일정, 장학제도 등 신입생 필수 정보가 전 영역에 걸쳐 정형화되어 있어 정확한 출처(Page) 표기에 적합함.2-2. 테이블 데이터 — 3일차 Text2SQL공공데이터 포털의 천안시 착한가격업소 공공데이터를 DB 테이블로 구축하였습니다.충청남도_천안시_착한가격업소_20260326 (단일/정규화 테이블)컬럼명데이터 타입설명연번 / 지정번호BIGINT / TEXT업소 식별 고유 번호업소명 / 대표자TEXT상호명 및 대표자 성명업종TEXT한식, 중식, 경양식, 이미용업 등 업종 분류읍면동 / 행정동TEXT업소 소재지 지역구분소재지주소TEXT도로명/지번 상세 주소데이터기준일자TEXT공공데이터 업데이트 일자3. 테스트 질문RAG — 신입생 가이드 내용 및 절차 문의 (2일차)Pythonquestions = [
