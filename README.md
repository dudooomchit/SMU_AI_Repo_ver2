# 상명 AI Training · 팀 프로젝트 (2·3일차) RAG · Text2SQL 기반 데이터 조회 시스템
## 개요

* **2일차 팀프로젝트 (문서 기반 RAG):** Retrieval 방식을 이용하여 신입생들의 원활한 학교생활을 위해 신입생 설명회 PDF를 기반으로 답변하는 챗봇 제작 (`2026_freshman_c.pdf`)
* **3일차 팀프로젝트 (테이블 데이터 조회):** 충청남도 천안시 착한가격업소 데이터를 활용하여 업소명, 업종, 대표자, 읍면동, 행정동, 소재지 등의 정보를 조회 후, 업종별 및 지역별 착한가격업소 현황과 분포를 분석할 수 있는 데이터 조회 시스템 구축 (`충청남도 천안시_착한가격업소_20260326.csv`)

## 1. [2일차] RAG — 문서 기반 대학생활 안내 시스템

### 문제점
수십~수백 쪽 분량의 신입생 가이드/설명회 PDF 내에서 학사 일정, 수강신청, 장학금, 편의시설 정보 위치를 빠르게 찾기 어려움.

### 해결책
의미 기반 검색(RAG)을 활용하여 사용자의 질문과 가장 연관성이 높은 페이지를 자동 검색 후, LLM이 이해하기 쉬운 가이드라인 형태로 변환하여 제공.

### 사용 데이터
* **파일명:** `2026_freshman_c.pdf` (2026학년도 신입생 설명회 가이드)
* **발행 기관:** 상명대학교 (2026)
---

## 2. [3일차] Text2SQL — 착한가격업소 현황 및 분포 분석

### 문제점
텍스트 문서 검색 방식으로는 "OO동 한식 업소 총 몇 개?" 또는 "지역별 업종 분포 비율"과 같은 집계·분석성 질의 처리가 비효율적임.

### 해결책
CSV 파일의 구조화된 테이블 데이터를 PostgreSQL(Supabase) DB로 정규화 구축하고, 자연어를 SQL문으로 변환(Text2SQL)하여 정확한 데이터 수치 추출 및 정형화된 통계 분석 제공.

### 사용 데이터
* **파일명:** `충청남도 천안시_착한가격업소_20260326.csv`
  
| 컬럼명 | 설명 |
| :--- | :--- |
| **연번 / 지정번호** | 업소 식별 고유 번호 |
| **업소명 / 대표자** | 상호명 및 대표자 성명 |
| **업종** | 한식, 중식, 경양식, 이미용업 등 업종 분류 |
| **읍면동 / 행정동** | 업소 소재지 지역 구분 |
| **소재지주소** | 도로명/지번 상세 주소 |
| **데이터기준일자** | 공공데이터 업데이트 일자 |
---


## 3. [4일차] 2, 3일차 기반 데모 프로그램 제작

## 상명대 새내기 도우미 챗봇 (RAG & Text2SQL 에이전트)
### 프로젝트 배경 및 목적
* **배경**: 대학 신입생은 학사 일정, 수강신청, 장학금 등 수백 쪽에 달하는 학사 가이드북 PDF에서 필요한 정보를 직접 찾기 어려워 정보 파편화 문제를 겪습니다.
* **목적**: 
  1. 비정형 문서(학교 학사 가이드북)를 위한 **RAG (Retrieval-Augmented Generation)**
  2. 정형 데이터(천안시 착한가격업소 공공데이터)를 위한 **Text2SQL**
  두 시스템을 **LangGraph 에이전틱 워크플로우**로 통합하여 신입생의 대학 생활 및 주변 생활 정보 접근성을 획기적으로 향상시킵니다.


### 예시 질문 리스트
1) 천안시 착한가격업소 중 중식 업종의 소재지를 알려주세요. (Text2SQL)
2) 수강신청 일정은 언제인가요? (RAG)
3) 장학금은 어떻게 신청하나요? (RAG)
4) 신부동에 위치한 착한가격업소 상호명과 주소를 보여줘 (Text2SQL)
5) 상명대학교 공과대학교학팀 전화번호를 문서에서 찾아와줘 (RAG)
6) 천안시 착한가격업소 중 한식 업종의 대표자를 정리해주세요. (Text2SQL)



### 챗봇 데모 실행 결과 (Demo Execution)

사용자 질문의 의도를 분석하여 RAG 기반 문서 검색 또는 SQL 기반 DB 조회를 자동으로 수행한 6가지 핵심 데모 예시입니다.
